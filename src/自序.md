# 自序

为什么叫“摩登纪谭”，“纪谭”一词的灵感来源于南宋的《云卧纪谭》一书，对于这本书之所以印象深刻，是因为关于浮山法远禅师的记载，《五灯会元》、《禅林僧宝传》这类灯录对于法远禅师的记载，都不够详细，比如没有何时圆寂这样的信息，但是《云卧纪谭》却给出了法远禅师较为详细的生平履历的相关记载，作者主要是根据浮山的碑刻信息来记载的。我的这本书主要也是根据自己实地到各大祖庭探访，再结合现在可以看到更多的资料，尽可能的讲述每一位禅师的过往，因为更多资料的缘故，可能也会出现不同于传统灯录的记载，所以模仿《云卧纪谭》的这个书名，至于“摩登”则是我现在临时居住的小区名称的一部分。

文章主要分成两类：游记、考证。游记类，只要带“记”，都是我亲自到访的地方，除了实地见闻外，还会有结合文献资料做一些考证。考证类，这类文章属于纯考证，灵感来源不限于我去过的地方。
